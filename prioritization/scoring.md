# Opportunity Prioritization (D6)

Scores live in `scores.json`; the table below is generated by
`python3 analysis/score_table.py` (verify freshness with `--check`). Each
dimension is 0–3 per the rubrics.

## Rubrics (0–3 per dimension)

- **Application value (App):** 0 none named · 1 plausible user, unnamed
  workflow · 2 named workflow/role it would serve · 3 drops into an existing
  operational workflow with an identifiable owner.
- **Scientific relevance (Sci):** 0 none · 1 supports science incidentally ·
  2 addresses a named Earth-science question/measurement linkage · 3 opens a
  new measurable science capability.
- **Novelty (Nov):** max of the card's four novelty sub-scores, discounted by
  1 if a corpus work already does something close (per card field 13).
- **Scalability (Scale):** 0 per-pair human effort · 1 capped small archive ·
  2 large fixed archive · 3 grows automatically at ~zero marginal cost.
- **Data availability (Avail):** 0 restricted · 1 negotiated access ·
  2 open with friction (keys, scraping) · 3 open key-free APIs verified live.
- **Grounding quality (Ground):** 0 language mostly not evidenced by geodata
  (AP-4) · 1 substantial noise/aggregation risks needing heavy QC · 2 bounded,
  known risks with stated mitigations · 3 language directly evidences pixels.
- **Construction feasibility (Feas):** 0 research problem · 1 major
  engineering · 2 moderate pipeline work · 3 deterministic join + templates,
  buildable immediately.

## Selection for demonstration (4 of 11)

1. **`pager-shakemap-impact-briefs` (rank 1, 18).** Highest score outright:
   operational-workflow value (App 3), unexploited expert text (Nov 3), open
   verified access, deterministic per-event pairing (Feas 3). Exercises MP-3 +
   MP-4.
2. **`afd-hydro-outlook-pairs` (rank 2, 16).** Top of the 16-point tier on
   scalability (daily-growing archive, Scale 3) with sound grounding (2);
   extends the corpus-proven expert-text family (MP-3) into unexploited
   product sections.
3. **`cmr-summary-product-grounding` (rank 3, 16).** Ties rank 2 on total;
   chosen over ranks 4–6 for maximal NASA-internal alignment (Earthdata) and
   metapattern coverage (MP-5 knowledge bridging — otherwise undemonstrated).
4. **`eonet-worldview-event-narration` (rank 7, 15).** Feasibility pick, per
   its 3/3/3 on Scale/Avail/Feas — the only card fully constructible by
   deterministic join + templates with zero parsing risk; demonstrates the
   pure MP-4 pipeline end-to-end and anchors the demo set with the
   highest-volume construction.

**Not selected, and why (score-referenced):**
- `earth-observatory-story-grounding` (16): article↔image keying is real
  engineering (Feas 2) with no offsetting workflow owner beyond
  communications; MP-3/MP-5 already covered by selections 1–3.
- `globe-ground-truth-captions` (16): Ground 1 — live-sample crowd noise
  (null captions, misclassifications) means a credible demo needs a QC study
  first, not a 100-pair sample.
- `nass-crop-condition-scenes` (16): Avail 2 — requires an API key
  (account signup), which this phase does not perform; strongest candidate
  for the next round once a key exists.
- `ground-failure-terrain-explanations` (15): Ground 1 — demo pairs would
  echo model output without the observed-slide validation the card itself
  requires.
- `astronaut-photo-geocaption` (14), `gbif-habitat-satellite-scaling` (14),
  `eonet-advisory-source-briefs` (13): dominated on score; the GBIF card is
  additionally a scale-out of corpus EcoWikiRS (discounted novelty), and
  advisory intensity rests on non-visual data (Ground 1).
